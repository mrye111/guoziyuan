# 果子园 · 第一期设计指南

> 本文件是第一期（MVP）的设计规范存档，开发与二期迭代均以它为准。

## 一、定位与目标

- **一句话定位**：果子的官方应援小站——粉丝看直播动态、补高能切片、留言互动的家
- **第一期目标**：上线可用、风格立住、互动有记忆点。不做账号体系，不做打榜排行（留到二期）
- **页面结构**：单页式长滚动站点，5 个版块 + 页脚

## 二、视觉规范

### 配色

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 果绿 | `#7BC96F` | 按钮、标题强调、图标 |
| 辅色 蜜桃粉 | `#FFB6C1` | 爱心、应援元素、标签 |
| 点缀 奶油黄 | `#FFE08A` | 徽章、高亮背景 |
| 背景 奶白 | `#FFFDF7` | 页面底色 |
| 深色文字 | `#4A3F35` | 暖灰棕，不用纯黑 |
| 浅色文字 | `#9C8F83` | 次要信息 |

### 字体与圆角

- 标题：站酷快乐体 / 资源圆体（圆润可爱），正文：思源黑体 Regular
- 圆角体系：卡片 20px、按钮全圆角（pill）、图片 16px
- 阴影：`0 6px 20px rgba(123,201,111,0.15)` 果绿色软阴影，不用灰色生硬投影

### 图形语言

- 手绘涂鸦风装饰：波浪虚线分隔、小叶子/小星星贴纸散落边角
- 所有图标用 2px 描边圆头线性图标（Lucide 风格）
- 装饰水果元素：苹果（果子的本体）、桃子、草莓三种，统一扁平插画风

## 三、页面结构（自上而下）

**1. 导航栏（吸顶）**
左侧「🍎 果子园」LOGO，右侧锚点链接：直播日历 / 高能切片 / 粉丝墙 / 留言树。滚动时导航栏变半透明毛玻璃。

**2. 首屏 Hero**
- 大标题「欢迎来到果子园」+ 副标题「主播果子的官方应援小站」
- 右侧/下方：果子 Q 版形象插画（第一期可用 AI 生成占位）
- 顶部一条「直播状态横幅」：直播中显示红色呼吸圆点 + "果子正在直播，快来看！"；未开播显示"下次直播：周六晚 8 点"（第一期用静态配置，不接 API）
- 背景：淡淡的果绿色渐变 + 缓慢漂浮的小水果/气泡

**3. 直播日历**
- 本周直播排期卡片（周一~周日横排），直播日高亮果绿底，今天加"今天"小徽章
- 下方附一行"记得设好小闹钟哦 ⏰"

**4. 高能切片**
- 视频卡片网格（3 列，移动端 1 列）：封面图 + 标题 + 播放量 + 日期
- 点击跳转到 B站/抖音原视频（第一期不做内嵌播放器）

**5. 粉丝墙（作品展示）**
- 粉丝二创图/表情包/手绘的瀑布流展示，图片下方标注作者昵称
- 顶部一行说明"想上墙？投稿到 xxx@xxx.com"

**6. 留言树（第一期核心互动）**
- 页面中部一棵插画大树，粉丝提交的留言以"小果子"便签形式挂在树枝上
- 底部表单：昵称 + 留言（限 50 字），提交后新果子动画"长"到树上
- 第一期无后端方案：留言存 localStorage，仅自己可见，并明确提示；或直接做成"写信给果子"跳转邮箱/表单

**7. 页脚**
「果子园 · 用爱意浇灌每一天 🌱」+ 各平台账号入口图标（B站/抖音/微博）

## 四、动效规范

| 场景 | 动效 | 参数 |
|---|---|---|
| 首屏入场 | 标题逐字弹入 + Q版形象从上方掉落弹跳 | cubic-bezier(0.34, 1.56, 0.64, 1) 弹性缓动，600ms |
| 背景氛围 | 小水果/气泡缓慢上浮漂浮 | 仅首屏，8~12 个元素，30s 循环，透明度 0.3 |
| 卡片 hover | 上浮 4px + 阴影加深 + 轻微倾斜 | 200ms ease-out |
| 滚动入场 | 各版块淡入 + 上移 20px | IntersectionObserver 触发，500ms，仅播放一次 |
| 留言提交 | 新果子从树干"长"出并弹跳挂到树枝 | 弹性缓动 800ms，配合轻快音效（可关） |
| 按钮点击 | 应援/点赞按钮爆出 6~8 颗小爱心粒子 | 一次性粒子动画 |

**硬性原则**：
- 装饰性粒子只出现在首屏和留言树，内容区保持干净
- 所有动效尊重 `prefers-reduced-motion`
- 移动端去掉漂浮粒子，保流畅

## 五、技术建议

- React + Tailwind（或纯 HTML 单页也可，第一期规模小）
- 动效：CSS transition + 少量 GSAP 或原生 Web Animations
- 内容数据（直播排期、切片列表、粉丝墙）第一期全部写在 JSON 配置文件里，改内容不改代码
- 移动端优先适配，粉丝大概率手机访问

## 六、第一期不做（明确砍掉）

用户登录、打榜排行、实时直播状态 API、后端留言板、商城。这些全部留到二期，先把"可爱、Q 弹、有记忆点"立住。
